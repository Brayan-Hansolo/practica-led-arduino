# Practica LED Arduino

Este proyecto consiste en un circuito básico utilizando Arduino UNO, un LED rojo y una resistencia de 220 ohmios.

## Funcionamiento
El LED parpadea cada 500 milisegundos utilizando el pin 13 del Arduino.

## Componentes utilizados
- Arduino UNO
- LED rojo
- Resistencia 220Ω
- Protoboard

## Código
El programa enciende y apaga el LED continuamente cada 0.5 segundos.
